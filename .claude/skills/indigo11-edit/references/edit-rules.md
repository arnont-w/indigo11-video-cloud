# Edit rules (Indigo11 editing skills)

Numbered rules the skills cite as "edit-rules #N" (`indigo11-edit` jobs A analyse, B clean-cut, C CapCut, D cutout, E styles; `indigo11-transcribe`; `indigo11-find-assets`). Outputs: `projects/_work/<skill>/<basename>/`; keys: `.env` at the pack root. `$SKILL_DIR` = `.claude/skills/<name>`; run from the pack folder (Windows: `python`, never bare `python3`). Merged from the old `edit-rules.md` and `editorial-rules.md` (rough-cut rules: #36); numbers are kept because scripts cite them.

**Agent-neutral.** Rules describe work, not tools. No `AskUserQuestion`: ask in plain text. No subagents: do the pass yourself and write the same file and schema. No image viewer: do not guess from the transcript; write the honest flag (`visual_unverified`, or keep the STT spelling, #38). An unverifiable step is reported, never assumed. Skills pass files on disk; no cross-skill imports.

## Architecture rules

### 0. `context.json` first, decide second
Before any rough cut, jump cut or footage judgment, run Job A (`analyse_context.py`) and read `context.json`: `transcript_words[]` (ms), `silence_ranges_ms[]` (Silero VAD), `scene_changes_ms[]`, `frames[]`, `frame_grids[]`, `per_clip[]` (role, quality), `take_comparison[]` (`best_idx`), `pacing`, optional `text_events[]`, `motion[]`. Subagents get `context.json`, not raw transcripts.
### 1. SKILL.md is the contract; scripts stay boring
Scripts are deterministic helpers (ffmpeg, API calls, JSON patches). Smart steps live in the agent. If a fix needs LLM reasoning, change `SKILL.md` or `references/`, never move judgment into a script.
### 2. Transcribe saves 3 outputs from one STT call
`projects/_work/transcribe/<basename>/`: `raw-elevenlabs.json` (char-level, kept forever), `captions.json` (phrases + pass 1), `words.json` (N-word captions + pass 2), `meta.json`. Re-segment 1-4 words per group from the raw file without calling STT again.
### 3. `mode=full` is two-pass
Rough cut, render an intermediate mp4, run VAD on its audio, then jump EDL (VAD on the source hears dropped takes and leaks them in). Jump alone and rough alone are single-pass. A CapCut target may stay single-pass because cuts are not rendered.
### 4. Pad-bleed check
A 200 ms tail pad can reach 150 ms into the next DROPPED take and repeat a word ("ขั้น ขั้น"). Always run `editorial_pass.py` between the agent's `edl.json` and `apply_edits.py`, and tell the user what it fixed.
### 5. VAD beats ffmpeg silencedetect for Thai
Amplitude thresholds (-25 to -55 dB) cut soft particles (`นะครับ`, `ของ`, `อะไร`). Silero VAD hears speech by shape. Default to VAD; warn if the user insists on ffmpeg.
### 6. CapCut inject: patch a project CapCut made, never generate one
New edit flow: CapCut > New project > drag clips into the **Media panel only** > save > quit > ask the agent. Read `draft_meta_info.json` `draft_materials` (`file_Path`, `duration` in us, `width`, `height`, `metetype`); drop ghosts (empty path, missing file, under 100 ms). The timeline file is `draft_info.json` (macOS) or `draft_content.json` (Windows). After patching, mirror to 9 places or CapCut self-heals to the old state within ~30 s: root `draft_info.json`, `.bak`, `template-2.tmp`, `draft_meta_info.json` (`tm_duration`); under `Timelines/<UUID>/` (what "open" reads) the same three plus `template.tmp`; and `../root_meta_info.json`. Use `_capcut_lib.py`. A project whose timeline is already cut is ADD-ONLY (#42).
### 7. CapCut must be quit before every write, by the buyer
A live CapCut overwrites injected files within ~30 s. Ask the user to quit first. If the main GUI is alive, the write is REFUSED (it holds unsaved work; killing it caused the 2026-09-18 refund, #42). Leftover helpers (`lvoverseas`, CEF) are reaped automatically. Write ops call `ensure_capcut_closed(force=...)`, never `kill_capcut()`. `--force-kill` only after the buyer confirms nothing is unsaved. macOS detects with `pgrep -x CapCut` plus `pgrep -f /CapCut.app/` (`-fx` misses it); Windows uses `tasklist`/`taskkill`, and refuses when `wmic` is missing.
### 8. Question language
Ask in Standard British English (Thai if the user writes Thai). Thai words only as literal values or produced content.
### 9. Output folders
`projects/_work/<skill>/<basename>/`; override with `--output-dir`. Keep deliverables and `meta.json` (`{skill, version, source_video, ran_at, duration_seconds, params, outputs[], notes[]}`); drop intermediates unless `--keep-intermediates`. `capcut/<project>/backups/` is the buyer's undo: never pruned.
### 10. Never cut a sub-range with `-c copy`
Stream copy snaps to the previous keyframe (3-6 s on long-form), so the clip freezes at the start. Re-encode: `ffmpeg -y -ss S -i IN -t D -c:v libx264 -preset fast -crf 20 -r 30 -g 30 -keyint_min 30 -movflags +faststart -c:a aac -b:a 128k OUT`. When unsure, re-encode.
### 11. Thai captions need two post-process passes
Pass 1 (text, on `captions.json`): proper nouns, numbers, brand and Latin spelling, stutters, fillers, repeats across cuts. Pass 2 (breaks): the agent reads `phrases.json` (`word_segment.py --phrases-out`) and writes `breaks.json` (chunks, plus `{"src","text"}` where the screen differs from STT). `apply_breaks.py` checks no source character is lost and derives every timestamp and token. **The agent never writes a timestamp** (hand-edited times made karaoke drift). A phrase whose chunks do not rebuild its text falls back to the rule-based cut (listed as `fallback`). Every caption stays on screen at least 200 ms. Protocol: `references/post-process-protocol.md`.
### 11b. Caption gap-close, default ON
Phrase gaps of 20-500 ms make captions blink. `transcribe.py`, `word_segment.py` and `add_captions.py` extend each `end` to the next `start`: gaps up to 1.2 s are bridged; a longer gap holds 1.2 s then clears. Output carries `"gap_closed": true`; a second run is a no-op. Never close `raw-elevenlabs.json` or per-token times (karaoke accuracy). Opt out with `--no-gap-close`.
### 11c. Caption remap after a cut, no re-transcribe
`remap_captions.py` maps captions onto the cut timeline with an EDL `{"segments":[{"source_start_ms","source_end_ms","target_start_ms","target_end_ms"}]}` (legacy `{start_ms,end_ms}` sums targets). Build it from Job B, or from a hand-cut project with `capcut_to_edl.py --project`. Tokens straddling a cut are dropped, text is rebuilt from survivors, output sorted by target. Speed changes are not handled (warns); the raw file is never edited.
### 12. Cut captions by timing first, then Thai words
Counting tokens broke 32-37% of captions on a real 14-minute clip. `word_segment.py`: (1) phrases from timing (silence >= 0.3 s, or an STT space between clauses; a final char over 300 ms is hidden silence, #36); (2) words inside a phrase only; (3) units that never split (particle + word, number + unit, consecutive English words); (4) captions of about N words inside a phrase, orphans merged, nothing under 200 ms. **N = 1 is literal** (only flashes under 100 ms merge). Breakage after: rule-based 15-17%, agent breaks 6%. Use `nlpo3` (falls back to `newmm`; `pip3 install nlpo3 pythainlp`), never `attacut` (343 MB PyTorch). Protect names via `--custom-dict` or `proper_nouns[]`.
### 13. Media panel only, never the timeline
Timeline drags force order and cut choices on the user; the Media panel keeps planning with the agent. Save then quit (Cmd/Ctrl+S, then Cmd/Ctrl+Q). If `draft_materials` is empty, CapCut has not saved: ask for Cmd/Ctrl+S (blank saved projects have 0-byte draft files; that is normal, not corruption).
### 14. Time units
CapCut JSON = microseconds. Our EDLs and caption windows (`*_ms`) = milliseconds. Per-token `start`/`end` in `tokens[]`, ffprobe and ElevenLabs = **seconds (float)**. The field suffix is the contract. `add_captions.py` converts once; never pre-multiply token times.
### 15. CapCut multi-colour captions
Set all three or CapCut renders one flat colour: `useLetterColor: true` on each highlighted style range, `use_effect_default_color: false` on the text material, and outer `text_color` + `font_size` synced to the first style block. Karaoke = one sub-caption per token, each showing the full text with one token highlighted (larger, gold) (`add_captions.py --karaoke`).
### 16. Every caption carries `tokens` with real per-token timing
`word_segment.py` and `apply_breaks.py` emit `tokens: [{text, char_start, char_end, start, end}]` (seconds), with `text[char_start:char_end] == token.text`. Without `start`/`end`, karaoke splits the duration evenly and drifts ahead of the voice (visible only on playback). One token: proper nouns, `นะครับ`, compound Latin ("Sub Agent"); two: "55 นาที".
### 17. API keys live in `.env` at the pack root
`ELEVENLABS_API_KEY` (required), optional `GEMINI_`, `OPENAI_`, `XAI_`, `OPENROUTER_`, `PEXELS_`, `PIXABAY_` keys. Scripts load the nearest `.env` without overriding real env vars. No quotes or spaces around `=`. Never print, copy or send keys.
### 18. Agent decides, script computes
Scripts: API calls, ffmpeg, math (intersects, durations, offsets), nlpo3 segmentation, file I/O, the 9-place mirror, JSON validation. Agent: which clip is the hook, which take is wrong, is a name one word or two, should a caption merge. Misplaced logic is brittle, slow or non-deterministic.
### 19. Subagent passes
Transcribe 3-output: 2 passes (text fix; breaks). Clean-cut rough/full: 1 (word ranges to drop). `process_all.py`: 2 in parallel (assembly order; rough `keep_word_ranges`). `add_captions.py` N-word/karaoke: pass 2 if not yet run. Without subagents, run them in sequence. Never ship raw STT captions.
### 20. Ask only what the conversation has not answered
Scan the message and recent chat first; each signal skips a question. Batch up to 4, lead with a recommended default. "Quick, don't ask": use defaults but still confirm destructive ops.
### 21. Write order for CapCut ops
0 `ensure_capcut_closed` (live GUI and no force: refuse, write nothing); 1-3 reap leftover processes; 4 `sleep 5` (auto-save can still write after a kill); 5 re-check, abort if alive; 6 `begin_op()` snapshot BEFORE mutation; 7 write; 8 mirror 9 places; 9 `check_mirror`, roll back on a partial mirror. Step 0 decides whether the write is allowed; skipping it is the #42 refund.
### 22. Where new functionality goes
Deterministic op: `scripts/`. AI judgment: `references/<protocol>.md` loaded from SKILL.md. Cross-skill rule: `CLAUDE.md`. Skill UX: SKILL.md. Trigger phrases: SKILL.md `description`, never the body. No judgment in scripts, no math in prompts.
### 23. CapCut saves the Media panel only on Cmd/Ctrl+S
`read_media.py` reads `draft_materials[type=0]`; if empty, ask for a save and retry.
### 24. Saved styles live in `my-rules/`
`my-rules/style-<name>.md`, read only when the user names it; `save_style.py` (job E) captures one; "apply" = read it, then run the normal job. Rough-cut judgment still reads `context.json`.
### 25. Import the buyer's own files with `import_media.py`, no manual drag
Registration is three JSON writes: `draft_meta_info.json` `draft_materials[type=0]` (lowercase id), `draft_virtual_store.json` `type=1` `{child_id, parent_id: ""}`, then the 9-place mirror (#6). CapCut must be quit (#7). `--dry-run` previews; re-runs are idempotent; stills default to 5 s. Chain: find-assets downloads, `import_media.py` registers, `add_sfx.py`/`add_overlay.py` place. The buyer's local files only, never CapCut's online library (#35).
### 26. UUID case
Timeline JSON (`draft_info.json`/`draft_content.json`) ids: UPPERCASE (`new_uuid()`). `draft_meta_info.json` and `draft_virtual_store.json` ids: lowercase (`new_uuid_lower()`). Mixing gives "File not accessible".
### 27. Cutouts must be frame-synced: normalise VFR to CFR first
Phone clips are VFR; a matte written at the declared rate stretches ~5% and shows a ghost "double head". Job D (`cutout.py`) probes, transcodes to CFR if needed, mattes, verifies frame count and duration. Always use `<base>-cfr.mp4` as the original layer, never the raw input.
### 28. Free assets need source fallback chains
SFX: Mixkit, myinstants. Music: Mixkit, Incompetech, ccMixter. Meme/GIF: Klipy (optional key), Tenor, Giphy, Imgflip. B-roll: Mixkit, Coverr; English queries only. Plain HTTP with a browser User-Agent.
**Paid generation** (`gen_asset.py`, `gen_music.py`): keyed providers from the config chain (#31). Contract: `--estimate-only`, show the baht figure, get agreement, then generate. Prefer a still plus Ken Burns over video. Cost goes to `meta.json` `cost{}`.
**Licence tiers, always surface them:** Mixkit = commercial, no credit (default for brand edits); Incompetech/ccMixter = CC-BY, credit required (relay `meta.json` `credits[]`); myinstants/Klipy/Tenor/Giphy/Imgflip = restrictive, warn for paid work.
### 29. Analyse sees frames, not video
Sparse frames plus VAD plus `take_comparison` settle editorial calls for free. Any skill placing captions or overlays MUST Read the frames first (demos sit in silence, invisible in the transcript). Optional local passes, off by default: `--detect-text` (macOS Apple Vision OCR; skipped elsewhere) and `--detect-motion` (ffmpeg, any OS). Cloud understanding (`--understand`, Gemini key) is explicit opt-in. `context.json` `_schema_version` is `"4"`.
### 30. Loudness is measured, never guessed (default ON)
When voice mixes with BGM or SFX: (1) `normalize_audio.py <cut>.mp4 --target social` (-14 LUFS, TP -1.0); (2) `mix_bgm.py prep --voice ... --music ... -o bed.m4a` (music = voice minus 20 LU, 6 dB sidechain duck; use the bed at volume 1.0); (3) after render, `mix_bgm.py master final.mp4`. `mix_bgm.py measure <file>` answers "how loud is it". Peak lies: a stock track measured -19.3 LUFS against a voice at -26.6.
### 31. Provider config (optional)
Keys live in `.env`; optional provider ORDER goes in `~/.indigo11/config.json` `providers.<task>.chain` (`stt`, `tts`, `image`, `video_gen`, `music`, `video_understand`; `enabled` gates paid passes). Scripts pick the first entry that is implemented AND keyed, else the built-in order; env keys win and config holds no secrets. Defaults: STT ElevenLabs Scribe v2 (best Thai timing); TTS ElevenLabs v3/v4 only.
### 32. Cross-platform: macOS and Windows
Branch on `os.name == "nt"`; never replace the POSIX path. (1) Every text `open()` passes `encoding="utf-8"` (Thai Windows defaults to cp874). (2) Reconfigure stdout/stderr to UTF-8 on Windows. (3) Never call bare `python3`; use `sys.executable`. (4) Per-OS venv paths and `.cmd` shims (`shutil.which`). (5) No hardcoded `/tmp` or `/dev/null`; macOS-only features degrade with a clear message.
### 33. CapCut resource library: harvest from the buyer's machine
Stickers, effects, filters, sounds, fancy text and animations are added by pure-JSON patching (`_capcut_lib.py`). `resource_id`s change per version and region and no public search API exists, so: (0, mac, optional) `scan_capcut_cache.py` lists what the buyer has browsed; (1) harvest: the buyer adds items to a library project (`fxlib`), saves, quits; `extract_resources.py --project fxlib --json references/resource-catalog.json` stores ids, names and FULL material objects; (2) the agent picks by name; (3) `capcut_apply_resource.py --target P --source fxlib --resource-id|--name ... --start-ms --dur-ms` copies items onto a new track, with the mirror. Music, SFX, B-roll and AI images come from find-assets.
**Caption styling:** `--color`, `--base-size`, `--vertical-pct`/`--horizontal-pct`, `--border-width`/`--border-color`, `--shadow-alpha`/`--no-shadow`, `--karaoke`. Bilingual = two runs, one `--role` each (`captions-th`, `captions-en`).
### 34. CapCut has no headless export: render the draft with ffmpeg
Never promise a terminal export. `render_draft.py --project P` rebuilds cuts, scale/position/speed, canvas and text tracks (libass; `drawtext` cannot shape Thai) into `projects/_work/capcut-render/P/final.mp4`. Library effects, filters, transitions, stickers, text templates and animations are GPU shaders: the script exits 2 and lists them; offer CapCut's own export or `--allow-unsupported` (cuts + text only). Never downgrade silently. CapCut's "1080P" preset downscales; this renderer keeps the canvas.
### 35. Never call CapCut's catalogue API
Requests carry runtime `x-gorgon`/`x-argus` signatures; a hand-built or replayed client looks like a bot and can BAN a paying buyer's account. Do not even test once. The buyer browses, then `scan_capcut_cache.py` reads the disk. Stickers, text templates, effects and filters cache under a server-assigned `<hash>` and cannot be rebuilt from an id, so a shared id sheet only NAMES assets. Cached sounds are plain unnamed mp3s (usable via `import_media.py`; prefer find-assets). Transitions have no separate op.
### 36. Rough cut: narrative first, take quality second; never anchor a tail on STT phrase end
**Why (clip 0902, human cut 58.43 s):** judging only take quality kept flawless lines that say nothing (71.05 s vs 58.60 s). Most of the 12.4 s win was narrative (8.4 s), not the tail anchor (~4 s).
**Narrative pass (run FIRST).** Read the whole transcript, decide what the video is for, name the beats, assign every line to one. Shapes: product (Hook, Product, Proof/demo, Benefits, CTA), tutorial (Problem, Setup, Steps, Result), story (Hook, Context, Turn, Payoff), opinion (Claim, Evidence, Objection, Conclusion). Cut a line that adds no beat or restates one: (a) empty promise ("I recommend it" before naming the product); (b) dangling reference ("another model" after the first was cut; keep the setup or cut the line); (c) duplicate beat (the fuller line wins, whichever is first); (d) throat-clearing between hook and product. For several takes of one script, pick per beat (completeness, then delivery, then position) and log winners in `notes[]`. Verify no beat is EMPTY; a missing Proof/demo is worse than a long video.
**Take quality (among survivors).** Cut: repeated takes (last complete take wins; scan about 30 s around), false starts (rescue a useful phrase as a 1-2 s micro-segment), standalone fillers (EN `uh um er`; TH `เออ อ่ะ แบบ` as hesitation, `คือว่า อืม`), mid-sentence stumbles, dead air and silences of 500 ms or more, sound tags, meta-commentary. Keep: short emotional beats (1-3 s), Thai particles and conjunctions (`ครับ นะ แต่ ก็ เลย`), the speaker's pacing, loanwords with their Thai connector. Thai: work at phrase level; English stutters keep one instance.
**Padding.** Start about 200 ms early. **End = last REAL character (duration capped at 300 ms) + 150 ms**, never the phrase `end`: ElevenLabs stretches the final character over trailing silence (up to 3.2 s) and VAD end includes breath (backing off 250 ms ate 3 characters). "Real" = after dropping audio-event tokens and whitespace. Implemented in `compute_edl.py` (`real_speech_end_ms`) and `editorial_pass.py` (`trim_stretched_tails`); only pulls ends earlier. Merge kept segments within 300 ms; no fragments under 500 ms.
**Final 20%:** most retakes live there; keep the cleanest statement of each closing point and never delete the CTA. Opening: ONE take.
**Quality bar:** every beat present, every kept line names its beat; kept length roughly 30-50% of a raw recording with retakes (over 70% = missed retakes); no segment under 500 ms, gap under 50 ms or run over 5 s without a pause check; chronological, non-overlapping; `notes[]` logs every dropped retake, rescue, stumble and narrative cut.
### 37. The agent must SEE the footage: read frame grids
A silent stretch is usually the demo, so `pick_frame_times` samples about every 2 s inside any gap of 1 s or more. `frame_grid.py` (ffmpeg `tile`, local) packs frames into grid PNGs, listed in `context.json` `frame_grids[]`. Flag `--grid-cells` (36 default; 16 for small text). Read grids first, single JPEGs only for tiny detail. **Seeing is not keeping:** `compute_edl.py` drops ranges with no speech, so `decisions.json` takes `visual_keeps[]` (`{clip_index, start_ms, end_ms, reason}`), exempt from the VAD intersect. **Holding a silent shot over about 2 s is the BUYER's call:** name the range, ask, then write it.
### 38. Look before rewriting a proper noun
Thai STT spells brands phonetically, and a wrong spelling looks right. Before changing a proper noun, read the frames at that moment (`frame_grids[]`, or `frame_grid.py` on the source; use `--cells 16 --cell-width 900` for logos). If frames do not show the name (0902: device held 24 s, no logo), KEEP the STT spelling and flag it unverified in `notes[]`. Every changed proper noun is frame-verified or flagged. Pass 2 fixes boundaries only.
### 39. Inter-skill JSON: pin the schema in the prompt
Parsers fail silently on a wrong shape, so briefs carry the literal schema and its gotchas; verify against the parsing script. `keep-per-clip.json`: `{"kept":[{"clip":"IMG_1766","start_ms":4480,"end_ms":10120}],"_provenance":"..."}` (object with `kept`, ms, `clip` = file **stem**: `"IMG_1766.MOV"` matches nothing and is dropped silently; no `_provenance` reuses a stale keep from another project). `decisions.json`: string keys (int keys fall back to "keep whole clip").
### 40. Canvas follows the footage; cuts land on phrase boundaries
(a) A blank project at `original`/1920x1080 pillarboxes vertical clips. `inject_edl.py` derives the canvas from the media and reports `canvas_fixed`: orientation only, three-way (portrait 9:16, landscape 16:9, square 1:1; a bool `h > w` mislabels squares); a deliberate same-orientation choice (4:5) is left alone. (b) Every range starts and ends on a phrase edge from `words[]`. `compute_edl.py` lists breaks in `warnings[]`; read them and re-pick; an empty `warnings` is part of "done". The check is phrase-level and exempts the tail anchor (#36). A stutter inside a phrase: drop the phrase, keep the clean retake.
### 41. `qc_edit.py` answers "is this edit shippable?"
`verify.py` proves the JSON is sound, not that the edit is watchable. `qc_edit.py --project P [--json]` (about 0.05 s, no LLM) intersects VAD (sound), the ElevenLabs char stream (words) and the EDL (kept) and flags chopped words, kept sound with no words, kept words with no caption, split brand names, wrong canvas. **A FAIL is not shippable:** fix the cause, re-run, never hand over with a note. Run it last on every CapCut edit. **A warn is not a failure:** `cut_unverified`/`brand_unchecked` mean the check could not run; report what would settle it. Never re-cut to clear a warn.
### 42. Non-destructive by default
On 2026-09-18 "add captions" on a hand-cut project ran `process_all` > `compute_edl` > `inject_edl`, which REBUILT the video track; no snapshot, sale refunded. A prompt is only advice, so **the guarantee lives in the scripts**.
1. **Snapshot before every write:** `begin_op()` copies touched files to `projects/_work/capcut/<project>/backups/<op-id>/` with a `manifest.json` (`sha256`, `existed_before`). Exceptions and incomplete mirrors roll back. Backups are never deleted.
2. **ADD a track, do not replace one:** captions, SFX, overlays, stickers, effects, filters go on NEW tracks. `add_captions.py` owns its track per `--role` (`owned_tracks` in `state.json`) and updates it in place; any other track is the buyer's.
3. **Replace or delete needs a flag AND the buyer's yes:** `--replace-timeline` (`inject_edl.py`, `init_project.py`, `template_apply.py`), `--overwrite-owned` (our track carries their edits), `--force-kill` (#7). A refusal is the buyer's work talking. State the loss in numbers ("delete the N segments you cut"), non-destructive option FIRST.
4. **CapCut's own re-save is not an edit:** it snaps timing to its frame grid on open. Ownership compares text and style exactly, timing within 50 ms.
5. **Every emit carries the undo:** `op_id`, `backup_dir`, and `restore_project.py --project X --op <op-id>` (`--list` shows snapshots). Relay it to the buyer.
**The request decides the mode; timeline state only the permission level.** "Add captions" means captions, never cuts. On a hand-cut timeline: `verify.py` > `add_captions.py --from-timeline [--video-track N] [--audio-track N]` > `qc_edit.py` (refuses `speed != 1.0` and an ambiguous separate audio track).
## Core flow, job C (blank timeline only)
`verify.py` > preflight > `read_media.py` > `process_all.py` > agent decisions > `compute_edl.py` > `inject_edl.py` > optional `add_captions.py` > `qc_edit.py` > optional `render_draft.py` (#34). `_capcut_lib.py` owns `ensure_capcut_closed`, `begin_op`, `mirror_9_places`, `write_state`, UUID helpers. `restore_project.py` undoes any op. Job A feeds B and C; transcribe feeds A; find-assets feeds C via `import_media.py`. JSON shapes are a stable inter-skill API: version any change.
