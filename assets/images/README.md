# images/ · pictures you can use in any video

Put product photos, photos of people and other pictures you use often here. Claude can pick them up when you ask for B-roll, overlays or stickers.

- Use real pictures of real things (products, people, places).
- Use only pictures you have the right to use.
- If a picture is made by AI or is only an illustration, say so in the video or caption.
- Icons: put them in `assets/images/icons/` (SVG or PNG, named after what they show, for example `rocket.svg`). Claude looks here first, then free icon sets, then draws one as an SVG.
- Keep file names short, in English, with no spaces (for example `product-front.png`).
