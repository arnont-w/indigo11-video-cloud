# videos/ · clips you can use in any video

Put video clips you use often here (b-roll, places, products). Claude searches this folder first, before any website, when a video needs a shot.

- Use only clips you have the right to use.
- Name files and folders after what is in them, in English, no spaces (for example `tokyo-street-night.mp4`, `products/serum-pour.mp4`): the search matches those words.
- If a clip is made by AI, say so in the video or caption.
