ENGINE

Small helper files shared by the skills: finds Python, ffmpeg and your .env key file (_env.py), sound-effect lookup (sfx_roles.py) and the setup check (check_setup.py). Also here: save_result.py (files finished results into projects/results), voice.py (your own voice), render_frames.mjs + animation-starter.html (turn an animated web page into a moving video; needs Node 22 or newer and Chrome or Edge) and motion_check.py (tells you if a video is only still images). Leave it alone.
