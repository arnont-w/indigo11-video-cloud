# My rules: index

One line per file: `- file: what it holds`. Claude reads this index, then every file listed, except `style-*.md` files: those are read only when I name the style.
Keep each file under 160 lines. When a file grows, Claude follows the "Growing files" rule in CLAUDE.md.

- style.md: my overall editing style (caption size, colour, words per caption, music volume, transitions, B-roll habits)
- captions.md: caption rules that are only mine
- sound-and-music.md: sound-effect and music habits
- cutting.md: cutting and pacing habits
- other.md: anything that fits nowhere else (never brand facts: those go in `assets/brand/BRAND.md`)
